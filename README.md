# MAX Robot – Bluetooth

The `maxrobot_bluetooth` repository is part of the MAX open-source robotics ecosystem developed by **Mensch Robotics Private Limited**.

This repository focuses on Bluetooth connectivity and communication within the MAX Robot, providing a reference for understanding how Bluetooth technology can be used to establish wireless connections and exchange data between the robot and compatible external devices.

It serves as an introductory resource for developers and contributors interested in exploring Bluetooth integration within the MAX platform.

**Main Repository:** https://github.com/menschrobotics/maxrobot
